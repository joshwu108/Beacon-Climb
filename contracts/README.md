# Beacon Climb contracts

`openapi.yaml` is CONTRACT-v1.1 (1.1.0) for the synthetic vertical slice. Each implemented operation has request and response fixtures under `examples/<operationId>/`. Planned paths carry `x-planned: true`, return 501 if called before implementation, and are excluded from client mocks. Run `npm ci --prefix test/contracts` before `npm --prefix test/contracts test` (or `./test/contracts/validate_examples.sh` for the OpenAPI fixtures alone) in a clean clone. The package and lockfile are self-contained under `test/contracts/`. The scripts check the implemented fixture bodies and parameters against the OpenAPI schemas, the replay artifacts (`decisions/`), the event schemas (`events/`) and the RFC 8785 canonicalisation fixtures (`jcs/`). Error responses use `ErrorEnvelope` with a closed `ErrorCode` enum; `X-Request-Id` is returned on every response. `Idempotency-Key` and quoted `If-Match` are normative.
