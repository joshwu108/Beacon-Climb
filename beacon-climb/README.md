# Beacon Climb: PRD + Agent Planning Pack

This is a **planning starter**, not a running application. It contains a detailed product and research requirements document, a Codex kickoff prompt, shared agent rules, and project-scoped Claude Code / Codex agent definitions.

## Quick start (manual)

1. Create a fresh git repository for Beacon Climb or copy these files into its root.
2. Open Codex in that repository; submit the entire contents of `START_HERE_CODEX.md` (or simply ask Codex to read the file and follow it).
3. Inspect Codex's generated `/plans` files before approving any implementation work.
4. Open a second, independent Claude Code session in a separate git worktree. Assign it a scoped task from `plans/02-agent-allocation.md` or one of the provided specialist agents.
5. Never have Codex and Claude Code write the same files simultaneously. Merge branches only after integration testing.

## Files

- `BEACON_CLIMB_PRD.md`: comprehensive scope, architecture, ML, data governance, backlog, acceptance and agent strategy.
- `START_HERE_CODEX.md`: single copy-paste initial planning prompt.
- `AGENTS.md`: concise instructions Codex can use from repository root.
- `CLAUDE.md`: Claude Code conventions.
- `.claude/agents/`: specialized Claude Code subagents (YAML frontmatter Markdown files).
- `.codex/agents/`: sample narrow Codex agent definitions (TOML). Codex capability/model availability varies; no model is pinned.
- `docs/`: reserved for architecture, data audits, model cards.
- `plans/`: reserved for execution plans generated by Codex.

## Recommended first milestone

A route catalog, account, attempt logger, deterministic heuristic, and accessible mobile web UI that runs locally from a clean clone. **No neural model, Kafka or Flink required for that milestone.** Add them as measured, separately tested capabilities in later sprints.
